# The shell's own glyphs

Four icons, shipped with the bundle under the `shell:` prefix and registered by
`ShellBundle::prependExtension()`, so the shell's furniture draws itself
on an installation that has configured no icon set at all — including a freshly
fresh installation with no network access at build time.

They are **not** a design system. A host names its own icons in its own set; the
shell names only the four its own chrome needs (the sidebar's collapse chevron,
the tree's caret, the theme toggle, the module grid's lens marker).

Paths are from [Lucide](https://lucide.dev) (ISC License, © Lucide Contributors),
the same set the platform draws everywhere else.
